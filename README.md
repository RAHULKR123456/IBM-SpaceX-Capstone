# IBM Data Science Capstone — SpaceX Falcon 9

## Project overview

This project analyzes historical SpaceX Falcon 9 launch data to explore launch-site patterns, payload characteristics, landing outcomes, and landing-success prediction.

## Project notebooks

1. `01_Data_Collection_API.ipynb` — SpaceX API data collection attempt
2. `02_Data_Collection_Wikipedia.ipynb` — Historical Wikipedia launch-data extraction
3. `03_Data_Wrangling.ipynb` — Data preparation and target creation
4. `04_EDA_Visualization.ipynb` — Exploratory data analysis and charts
5. `05_EDA_SQL.ipynb` — SQL queries and launch-data summaries
6. `06_Folium_Interactive_Map.ipynb` — Interactive launch-site map
7. `07_Predictive_Analysis.ipynb` — Classification model development and evaluation
8. `08_Interactive_Dashboard_Plots.ipynb` — Interactive Plotly visualizations

## Tools and technologies

Python, pandas, SQLite, scikit-learn, Matplotlib, Seaborn, Folium, Plotly, and Google Colab.

## Data sources

The project uses historical IBM Skills Network SpaceX datasets and a historical Wikipedia page. The live SpaceX API request was attempted but returned connection errors during execution.

## How to reproduce

Open the notebooks in Google Colab and run the cells from top to bottom. Ensure that the dataset URLs are accessible and review each notebook's outputs.

## Results

The findings, model evaluation metrics, visualizations, and conclusions are documented in the notebooks and final presentation.

*This project was completed as part of the IBM Data Science Professional Certificate capstone exercise.*
